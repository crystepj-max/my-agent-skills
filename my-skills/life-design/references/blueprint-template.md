# 《个人人生设计蓝图》撰写规范

目标篇幅：**8000–12000 字**。写入 `人生设计档案/个人人生设计蓝图.md`。

## 四条贯穿全文的硬要求

1. **每个关键判断都要挂经历链。** 每个判断后面，必须能追溯到用户在访谈中讲过的具体经历，并**引用他自己的原话**。没有经历链的判断，不许写进蓝图。
2. **重力问题必须写清楚，不许含糊带过。** 如果看完这份文档，用户还觉得「只要我再努力一点就能改变」，这份蓝图就失败了。承认边界不等于认输，但必须写透。
3. **三个版本必须同样用力写。** 不许把任意一个写成陪衬，不许在文末暗示「我建议选第二个」。选择权归用户——你的工作是让三个版本都足够真实，让他能做出真正的选择。
4. **原型行动必须具体到本周能迈出第一步。**「多去了解一下」不算。「周四晚上约那个在做 X 的人喝杯咖啡，只问他三个问题」才算。

## 语气

像一个真正看懂了他的朋友，在认真地跟他说事。温暖，但不煽情；直接，但不冷。可以用一点幽默。禁止励志口号、禁止鸡汤、禁止「你一定可以的」。

**用户是来看清自己的，不是来被鼓励的。** 告诉他真相比让他舒服更重要——但真相要说得有温度。

## 蓝图结构

结构可依据用户实际情况自由组织，但以下九块必须全部覆盖。括号内为建议字数。

### 序章：这不是一份人生答案（约 600 字）

明确告诉用户这份文档的边界：

- 它不是答案，不是预测，不告诉你该选哪条路。
- 它的全部依据，是你自己讲出来的经历——所以它可信，也所以它可能不全。
- 它是一份「设计稿」，不是鉴定书。设计稿的价值在于可以改。
- 结尾回扣那句核心的话：**你不需要先想清楚自己热爱什么，我们会在行动、对话和反馈里，慢慢把它找出来。**

### 一、你在这里：四块仪表盘（约 1000 字）

摆出健康、工作、娱乐、爱四项分数，然后做解读，不要只是复述数字。

必须回答三件事：

1. **真正失衡的是哪一项？** 分数最低的那项未必是最紧急的——要看哪一项正在拖累其他项。
2. **哪一项长期被忽略？** 用户自己没提到、但你在对话中察觉到的那一项，要单独点出来。
3. **分数与叙述矛盾的地方在哪？** 比如娱乐打了 3 分，但聊起徒步时能量最高。矛盾之处往往是入口。

给一句总判断：比如「你的工作分数在撑着整个仪表盘——它不是优势，它是你唯一还在得分的地方，所以你不敢动它。」

### 二、真问题：你带来的那个问题，可能问错了（约 1200 字）

这一节是全篇的转折点，要写得够狠。

1. **他最初的问题是什么**（引用原话）。
2. **它为什么不是真问题**——指出它的假在哪里：是太抽象、是把手段当目标、还是把别人的期待当成了自己的。
3. **重力问题清单**：明确列出哪些属于不可改变的现实约束。每一条写清楚「它为什么不可改变」和「它带来的真实代价是什么」。**不许用「换个角度看」来敷衍。**
4. **重新定义后的真问题**：一个具体的、可以动手的新问法。
5. **这一节结尾要说清楚**：从假的题换到真的题，他少了什么、多了什么。

### 三、你的指南针：工作观 × 人生观（约 1200 字）

1. **工作观**：用一段话提炼（不要分点罗列他的原话），说清楚他为什么工作、工作与金钱/他人/世界的关系。
2. **人生观**：同样用一段话提炼，说清楚什么让他觉得没白活、他想怎样与家人和更大的世界连接。
3. **一致性分析**：三种结果之一——一致 / 妥协 / 冲突。
   - 若**一致**：指出正北方向在哪，以及他现在偏离了多少。
   - 若**妥协**：明确区分这是**有意识的取舍**还是**无意识的拖延**——这两者的出路完全不同。
   - 若**冲突**：不要调和，把冲突原样摆出来。告诉他这个冲突会在这三个版本里以不同形式重现。
4. **外部植入检测**：指出他的工作观里，有多少是自己的、有多少是父母/行业/同辈植入的。这一条容易伤人，但必须写。

### 四、你的能量地图（约 1200 字）

四类区域，每类下列出访谈中提到的具体的事：

| 区域 | 定义 | 写作要点 |
| --- | --- | --- |
| **核心区**（做得好 + 回血） | 真正该押注的地方 | 说明该主动争取什么，以及它在他当前生活里占多大比例 |
| **待开发区**（做得一般 + 回血） | 潜力最大，最容易被忽略 | 说明为什么值得投入——能力可以练，驱动练不出来 |
| **高消耗区**（做得好 + 抽干） | 被训练出来的能力，不是方向 | **明确说清「这不代表你要立刻辞职」**，给出渐进策略：如何减少比例、如何改变做法降低消耗 |
| **止损区**（做得一般 + 抽干） | 应尽量减少 | 给出替代方案、委托或协作建议 |

**心流的环境参数**（单独一小节）：把他的心流时刻拆成可复用的参数——独处还是协作、有没有即时反馈、有没有明确终点、允不允许犯错、什么时间段、什么物理环境。参数比内容更有用，因为具体的事他可能不会再做了，但参数可以搬到新的事情上。

**给一句总判断**：比如「你的能量主要消耗在 X 上，而它恰恰是你最不缺外部认可的地方——这意味着你有空间把它交出去。」

### 五、三个奥德赛计划（每套 800–1000 字，共约 2400–3000 字）

**这是蓝图的心脏。三套必须同样用力写，篇幅相当，语气相当。**

每一套固定包含五部分：

#### 1) 标题

一句简短有力的话，不要「方案 A」这种编号。标题要能让人一眼看到那是一种什么样的生活。

- 好的：「把副业做成主业的小工作室」「回到二线城市的另一种解法」「不再为别人的时间表活着」
- 差的：「继续现在的工作」「创业」「自由职业」

#### 2) 这个版本长什么样

用具体画面写，不要写抽象目标。**写五年后一个普通的周二**：几点醒、在哪、和谁、在做什么、晚上什么感觉。用现在时写，让它有质感。

#### 3) 五年时间线

按年或按阶段拆，每一段写清楚：这段时间主要在做什么、要跨过什么坎、什么算过了这一关。

```
第一年：……（主要在做什么）
第二至三年：……（关键转折）
第四至五年：……（它会变成什么样）
```

#### 4) 待验证问题（2–3 个）

这个版本里最不确定、最需要先用原型去试的部分。写成问题，不要写成待办。

- 好的：「我到底是不喜欢现在的工作内容，还是不喜欢为别人的目标负责？」
- 差的：「需要了解行业情况」

#### 5) 四项评估

| 维度 | 评分（0–10） | 说明 |
| --- | --- | --- |
| **资源** | | 现有的钱、时间、技能、人脉够不够启动 |
| **喜欢程度** | | 想到要过这种生活，身体的第一反应是什么 |
| **自信心** | | 你相不相信自己做得到 |
| **一致性** | | 它与你的工作观、人生观对不对得上 |

**评分要诚实。** 不要为了突出某一个版本而压低另外两个。每一项后面必须跟一句为什么是这个分数。

#### 6) 走这条路，你要放弃什么

**每个版本都必须写这一条，不许省略。** 没有代价的版本说明还没想透。

### 六、如果你已经倾向其中一个版本（约 1200 字，仅在用户明显倾向时写）

只在访谈中能明确看出倾向时才写这一节。**看不出来的话，跳过，不要硬猜。**

四个层次，从粗到细：

1. **本季度要验证的核心问题**（1–2 个）：不是「要不要转行」这种大问题，而是能在这个季度内被事实回答的问题。
2. **一个月内能做出的原型**：一个具体的、可完成的体验，不是调研。
3. **每天可以推进的小动作**：小到不可能失败的程度——每天 15 分钟这种量级。
4. **绝不愿牺牲的底线**：明确列出 3–5 条。底线的作用不是防止失败，是防止「成功了但变成了另一个人」。

### 七、原型行动清单（约 1000 字）

三类行动，按成本从低到高排列。全部必须具体到可以直接去做。

#### 类型一：一次人生对谈（成本最低，本周就能做）

找 1–2 个正在过某种生活的人聊一次。写清楚：

```markdown
### 对谈 N：[找谁聊]

- **找谁**：具体到哪一类人，最好给出用户访谈中提到的真实人选
- **问什么**：列出 3–5 个具体问题（不要问「你觉得这个行业怎么样」，要问「你上周最烦的一件事是什么」）
- **怎么判断这次谈话有价值**：可观察的指标
- **如果对方说的话让你不舒服**：那往往是最有价值的部分，写清楚为什么
```

#### 类型二：原型体验（一天到一周）

不是去了解，是去**过一小段**那种生活。

```markdown
### 原型 N：[一句话名字]

- **做什么**：具体到能直接执行的动作
- **什么时候**：具体到周几、大概多少小时
- **成本**：时间 / 金钱 / 人情
- **验证什么**：这个原型是为了确认或推翻哪个待验证问题
- **怎么判断成功**：可观察的结果（不是「感觉不错」，而是「做完之后你有没有想继续」「你有没有忘记时间」「你愿不愿意再来一次」）
- **失败意味着什么**：如果做完毫无感觉，说明什么，下一步怎么办
```

#### 类型三：本周第一小步

**只给一个动作。** 一个，不是三个。它必须小到本周内不可能做不到，且完成后会自然带出下一步。

**原则**：低成本、可逆、一周内能跑完。优先选指向「待开发区」的原型——能力可以练，驱动练不出来。每个原型都要写清楚「失败意味着什么」。不敢写失败标准的原型，不是原型，是许愿。

### 八、失败免疫（约 600 字）

把「失败」这件事重新定义清楚，说透，不要一笔带过：

- 这三个版本都可以先试再调。选错一个不意味着浪费了五年，只意味着你用一段真实经历换到了更准的信息。
- **原型失败留下的三种信息**：这条路不对 / 这条路的这个部分不对 / 你以为自己想要的东西，其实不是那个。
- 三种信息同样有价值，因为它们都不可通过空想获得。
- **唯一真正的失败是**：什么都不试，然后在五年后重复今天这段对话。
- 结合他访谈中的具体情况说一句——不要通用金句。

### 九、尾声（约 400 字）

收束全文。要点：

- 这份蓝图会随经历更新，它不是终稿。建议三个月后重读一次。
- 一句基于他具体情况的话——不要用通用金句，要针对访谈里最触动你的那个细节。
- 结尾把选择权明确还给他：三个版本摆在这里，下一步不是想清楚，是去试。

## 写作检查清单

完成后逐条自检：

- [ ] 每个关键判断都能追溯到具体经历，并引用了用户原话？
- [ ] 四个仪表盘解读了，而不只是罗列分数？指出了长期被忽略的那一块？
- [ ] 重力问题明确列出了？有没有写「它带来的真实代价」？
- [ ] 真问题重新定义了？重新定义后的问题有明确下一步吗？
- [ ] 三个版本篇幅相当、语气相当，没有任何一个是陪衬？
- [ ] 每个版本都写了「你要放弃什么」？
- [ ] 四项评估的分数诚实？每一项后面有没有写为什么？
- [ ] 高消耗区单独列出了，没有混进核心区？
- [ ] 原型行动具体到本周能执行？每个都有失败标准？
- [ ] 本周第一小步只给了一个动作？
- [ ] 全文没有励志口号、没有空泛赞美、没有暗示他该选哪个？
- [ ] 篇幅在 8000–12000 字之间？

任何一条没过，改完再交付。
