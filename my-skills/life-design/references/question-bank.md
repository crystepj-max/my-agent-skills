# 四阶段 · 问题库、追问钥匙与信号识别

本文件是 SKILL.md 的支撑材料。阶段顺序可灵活调整，但四个阶段必须全部覆盖。

**额度规则**：主问题 6–9 个（下表标「主问题」的都是）。苏格拉底式追问**不计入额度**，想追就追。典型配额：阶段一 2 个、阶段二 2 个、阶段三 1–2 个、阶段四 2–3 个，留 1 个余量给意外浮现的线索。

---

## 阶段一 · 你在这里

先定位，不谈方向。这一阶段最容易犯的错是：用户一开口就说「我想辞职」，你也跟着聊辞职。先把四块仪表盘摆出来。

### 主问题 1.1（默认开场第一问）

> 我们先做个简单的盘点。健康、工作、娱乐、爱这四个方面——健康包括身体、情绪和心理；娱乐指纯粹为了快乐而做的事，不是为了休息好接着干活；爱强调的是双向的关系，不只是你付出的那种。如果每一项 0 到 10 分，你会分别打几分？哪一项亮了红灯？

**追问钥匙**（按需插入，不要一次全问）：
- 「健康这块你打了 X 分，是身体、情绪还是心理拖下来的？」
- 「娱乐打这么低，是因为没时间，还是因为想不到有什么想做的？」（这两个原因指向完全不同的问题）
- 「爱这一项你说的是谁？」
- 「这四项里，哪一项你已经很久没想过它了？」

### 这条主线的信号识别

| 用户说 | 可能指向 | 需要再验证什么 |
| --- | --- | --- |
| 娱乐分很低，但聊起某件事时突然有能量 | 不是缺娱乐，是没把那件事算作「正经事」 | 追问他为什么不把它算进去 |
| 工作分高、其他三项都低 | 用工作填满了整个生活，风险在突然停下来的那天 | 追问「如果明天不用上班，你会怎么过一天」 |
| 健康分明显低于其他 | 往往是情绪和心理在拖，不是身体 | 追问最近一次觉得「撑不住」是什么时候 |
| 爱分低但说不出具体是谁 | 可能是关系存在但质量低 | 追问「上一次觉得被真正看见，是什么时候」 |
| 四项分数都集中在 5-6 分 | 典型的「说不上哪里不好，但就是说不上好」 | 这种状态最需要反向推演，让维持现状的代价显形 |

### 主问题 1.2

> 现在最让你焦虑、最想解决的人生问题是什么？

**这是整场对话最关键的一问。** 用户给的第一个答案，八成不是真问题。拿到答案后先做一件事：**判断它是可设计的真问题，还是重力问题**（判定表见文末）。

若属于重力问题，按「点破 → 承认代价 → 重新定义」三步处理，然后用重新定义后的版本继续追问。

若属于可设计问题，从下面**选一条**追问（这是备选清单，不是逐条要问的清单，一次只能问一个，其余留到后续轮次）：

- 「这个问题如果解决了，你的生活具体会有什么不同？」（要具体画面，不要抽象感受）
- 「你为这件事做过什么尝试？」
- 「这个焦虑是什么时候开始的？那前后发生了什么？」
- 「如果你不解决它，五年后你会怎样？」

> **这里是「补一问」陷阱最容易复发的地方。** 用户说出真问题之后，你会忍不住想立刻追问「为什么」。忍住——把你的好奇写成陈述句（「你说的是 X，我先按这个记下来」），把提问额度留给下一轮。

**另外，这一轮不要下判断。** 用户刚说出他的焦虑，你此时最多只能说「我有个还没验证的猜测」。过早给出「你真正的问题是 X」会让后面几轮变成找证据印证你的偏见。

### 主问题 1.3（可选 · 反向推演，必须先征得同意）

> 我想请你做一个有点残酷的想象，如果你现在状态不太适合，我们随时可以跳过。假设接下来五年，你什么都不改变——不是变糟，就是照现在的样子继续。那么五年后，一个普通的周二，你会怎么度过？从早上醒来开始说。
>
> 好，现在把这幅画面再往后拉五年，到十年后。那个周二的你，身体怎么样？身边是谁？心里在想什么？

**追问钥匙**：
- 「描述这个画面的时候，你身体是什么感觉？」
- 「这十年里，你放弃了什么？」
- 「这个画面里，最让你受不了的是哪一部分？」（这一问直接指向真问题）
- 「如果这个画面其实可以接受，那说明什么？」（少数情况下用户会发现维持现状没有代价，那也是重要信息）

**跳过条件**：用户明显处于低谷、情绪脆弱、正经历重大丧失（失业、分手、丧亲、重疾）时，跳过此问。

**判断依据是状态，不是措辞。** 不要等用户说出「活着没什么意思」才判定——多数人不会这么说。看以下信号，满足两条即跳过：

| 信号 | 具体表现 |
| --- | --- |
| 行为退缩 | 长时间卧床、退出社交、停止原本在做的事 |
| 语言平坦 | 回答很短、没有细节、反复说「不知道」「随便吧」「都行」 |
| 对未来无话可说 | 问到以后，答不上来，或者只有「没想过」 |
| 能量项极低 | 四维打分中健康项低于 3 分 |
| 近期丧失 | 半年内经历分手、失业、丧亲、重疾 |

有疑问时，按「跳过」处理。少做一次反向推演只是少一条素材；在低谷时逼他想象更糟的十年，是真实的伤害。

## 阶段二 · 你的指南针

工作观和人生观要分开问，然后由你做一致性比对。比对是你在反馈里说出来的，不额外占用提问额度。

### 主问题 2.1 · 工作观

> 我想问一个可能不太好回答的问题：你为什么工作？工作对你来说，赚钱占多大比重？它和你之外的其他人、和这个世界，是什么关系？

**追问钥匙**：
- 「如果钱的问题完全解决了，你还会工作吗？会做什么？」（注意：多数人答不上来，答不上来本身是信号）
- 「你做过的工作里，有没有哪一段你觉得『这段时间没白干』？那段和现在有什么不同？」
- 「你觉得工作应该是快乐的吗？」（这一问能区分「忍受型」和「意义型」，不必纠正他的答案）
- 「你父母是怎么看待工作的？他们的态度对你影响大吗？」

**信号识别**：
- 回答里出现大量「应该」「必须」「没办法」→ 工作观是外部植入的，不是自己的。
- 回答里出现「我们」「团队」「用户」→ 工作的意义锚点在他人，这类人在纯个人成就的路径上会空虚。
- 回答里出现「做出来」「解决掉」「弄明白」→ 意义锚点在做事情本身，这类人更需要自主权而不是认可。
- 说不清为什么工作 → 这不是缺点，是这次对话要补的第一课。

### 主问题 2.2 · 人生观

> 换一个更大的问题：什么会让你觉得，这一生没有白活？以及，你想怎样和家人、和更大的世界连接？

**追问钥匙**：
- 「如果到你七十岁，回头看，有一件事没做到你会遗憾，那是什么？」
- 「你希望别人在你离开后，怎么说起你？」
- 「家人这两个字，对你来说具体包括谁？」
- 「更大的世界——你关心过什么跟你个人利益无关的事吗？」

**信号识别**：
- 人生观里出现「自由」「不被管」→ 注意区分是真的想要自主，还是想逃离某个具体的人或环境。追问：「你逃离的那个东西具体是什么？」
- 人生观里出现「留下点什么」→ 意义锚点在创造与传承，纯消费型的生活会让他空虚。
- 人生观里只有家人、没有自己 → 常见于长期承担照顾责任的人，要温和追问「那你自己呢」。

### 一致性比对（你来写，不用问）

拿到两块之后，在反馈里直接说出你的观察。三种典型结果：

| 结果 | 表现 | 你要说的话 |
| --- | --- | --- |
| **一致** | 工作观和人生观指向同一个东西 | 直接指出正北方向在哪，并说明他现在偏离了多少 |
| **妥协** | 工作观服务于现实，人生观被搁置 | 指出这个妥协是**有意识的取舍**还是**无意识的拖延**——这两者差别巨大 |
| **冲突** | 两块直接打架 | 不要调和，把冲突原样摆给他看。冲突本身就是最重要的信号 |

## 阶段三 · 寻路

### 主问题 3.1 · 心流时刻

> 过去一年，或者更早也行——有没有哪些时刻，你做着做着就忘了时间，抬头发现两三个小时过去了？

**追问钥匙**（这一问的追问极其重要，不要急着推进）：
- 「当时具体在做什么？」
- 「和谁在一起？还是一个人？」
- 「在什么环境里？在家、在公司、在外面？」
- 「那件事有报酬吗？有人要求你做吗？」
- 「做完之后是什么感觉？」
- 「这种状态最近一次出现是什么时候？频率怎么样？」

**信号识别**：
- **心流的「环境参数」比「内容」更有用**。用户可能再也不会做那件具体的事，但那个环境参数（独处 / 有人即时反馈 / 有明确终点 / 允许犯错）是可以复用的。追问时重点抓参数。
- **一个人还是和谁在一起，是硬参数**。独处心流的人塞进高密度协作环境会枯萎，反之亦然。
- **没有报酬、没人要求**，这两条同时满足才是高纯度信号。
- **频率骤降是警报**。用户说「以前经常有，这两年没有了」——这两年发生了什么，往往就是真问题的入口。

### 主问题 3.2 · 能量三分

> 我们做个分类。第一，哪些事做完你是回血的，虽然身体累但精神上更想干活了？第二，哪些事做完明显把你抽干？第三——这个最重要——有没有哪些事你做得很好、别人评价也不错，但你其实并不热爱？

**追问钥匙**：
- 「抽干是什么感觉？是空、是烦、还是身体上有反应？」
- 「既然这么累，为什么还在做？」（这一问常牵出外部期待或沉没成本）
- 「做得好但不热爱的那些，如果明天不用做了，你第一反应是解脱，还是舍不得？」（关键分水岭）
- 「这三类里，哪一类占了你日常的大部分时间？」

**信号识别**：

| 表现 | 归类 | 在设计里的地位 |
| --- | --- | --- |
| 做得好 + 回血 | **核心区** | 应该主动争取更多 |
| 做得一般 + 回血 | **待开发区** | 潜力最大，最容易被忽略。能力可以练，驱动练不出来 |
| 做得好 + 抽干 | **高消耗区** | 是被训练出来的能力，不是方向。必须单独列出，不许混进核心区 |
| 做得一般 + 抽干 | **止损区** | 现实里应尽量减少、委托或外包 |

**「做得好但不热爱」是这一阶段最大的陷阱。** 人会本能地把擅长的事当成方向，因为那是他最容易被认可的地方。必须把它单独拎出来，并明确追问「如果可以不做，你第一反应是什么」。

**待开发区最值得投入。** 做得一般但做完回血，说明能力还没长出来，但底层驱动是真实的——这往往是原型行动最该验证的方向。

## 阶段四 · 摆脱困境与创造可能

### 主问题 4.1 · 锚问题

> 有没有一件事，是明知道已经走不通了，你却一直不愿意放手的？一个方案、一个念头、一个你曾经很确定的方向。

**追问钥匙**：
- 「你第一次有这个想法是什么时候？」
- 「它曾经是对的，对吗？那时候是什么情况？」（承认它曾经有效，用户才放得下）
- 「现在是什么让你觉得它走不通了？」
- 「如果彻底放弃它，你会失去什么？」（**这一问是核心——答案就是他真正想守住的东西**）
- 「那个你想守住的东西，除了这条路，还有别的走法吗？」

**信号识别**：
- **锚问题几乎从来不是关于那件事本身。** 想创业的人放不下的往往不是公司，是「不想再被人管」；想考某个学校的人放不下的往往不是学历，是「想证明自己不比谁差」。
- **区分「放弃」和「完成」。** 有些执念不需要放弃，只需要承认它已经完成了它的历史任务。这个说法常常能让人松手。
- **迟迟不松手的信号**：用户反复回到同一个方案，每次都补充新的可行性论证，但没有任何新动作。

### 主问题 4.2 · 版本二（第一条路消失）

> 现在做一个假设：你现在正在走、或者盘算很久的那条路，明天彻底消失了——不是你放弃它，是它不存在了。你会去做什么？

**追问钥匙**：
- 「为什么是这件事？」
- 「这件事你其实已经偷偷想过很久了吧？什么时候开始的？」
- 「如果真的去做，你第一步会做什么？」

### 主问题 4.3 · 版本三（不考虑钱和评价）

> 再假设一件事：钱完全不是问题，而且没有任何人会评价你的选择——你父母不会，你朋友不会，社交媒体上的陌生人也不会。你会过什么样的生活？

**追问钥匙**：
- 「这个想法你跟别人说过吗？」（很多人从未说出口，说出来本身就有效）
- 「为什么没说过？」
- 「这个版本里，你每天的周二会怎么过？」（要具体画面，滤掉幻想）
- 「这个版本和上一个版本，区别到底在哪？」（**如果两个版本撞车，说明用户其实只有两个想法，必须追问区别**）

### 主问题 4.4 · 收敛（仅在用户明显倾向某一版本时问）

> 这三个版本摆在这里，我注意到你聊到第 X 个的时候，语气不一样——说的细节也更多。你自己感觉到了吗？如果我们先拿这一个做实验，这个季度你最想确认清楚的，是哪一件事？

**追问钥匙**：
- 「一个月内，你能做出的最小版本是什么？」
- 「每天能推进的最小动作是什么？」
- 「走这条路，有什么是你绝不愿意牺牲的？」（底线必须问出来，否则原型会走偏）
- 「什么情况出现，你会知道自己走错了？」

## 重力问题：判定与重定义手册

### 判定三步

拿到用户的问题，依次问自己：

1. **这件事会因为他的努力而改变吗？** 不会 → 重力问题。
2. **他是不是已经为此努力很久了？** 努力很久而毫无进展，是重力问题的强信号。
3. **问题的表述里有没有「什么时候才能」「为什么偏偏是我」？** 有 → 几乎一定是重力问题。

### 重定义三步（话术）

1. **点破**：「我想说一句可能有点直接的话：这件事，不是靠你更努力能解决的。」
2. **承认代价**：「而且这件事确实不公平。它带来的损失是真的，我不会劝你想开点。」
3. **转向**：「所以我想把它换一个问法——在它已经是这样、而且不会变的前提下，你还能设计什么？」

### 常见重力问题对照表

| 用户的问题 | 重力部分（不可改变） | 重新定义后的可行动问题 |
| --- | --- | --- |
| 38 岁还能转行吗 | 年龄不可逆，招聘偏见客观存在 | 在年龄既定的前提下，哪条路径对年龄最不敏感？ |
| 行业在下行，怎么办 | 行业周期不由个人决定 | 这个行业里哪部分能力可迁移？先迁移哪一个？ |
| 父母不认可我的选择 | 他人的态度不由你决定 | 如果不以他们的认可为前提，这个选择还成立吗？我要怎么说明而不说服？ |
| 我已经在这个城市扎根了 | 家庭、房产、社会关系是既成事实 | 在不动根的前提下，我能把多少比例的生活挪到别处？ |
| 我错过了最好的时机 | 时间不可逆 | 现在入场，需要付出什么额外成本？我付得起吗？ |
| 我的身体不允许了 | 具体健康限制 | 在这个限制内，哪部分是我还能完整做到的？ |
| 我孩子还小，走不开 | 育儿责任在数年内是硬约束 | 这三年，我能做的最小准备是什么？ |

### 注意

**重定义不是安慰。**「换个角度想」是无效的话术。真正的重定义必须产出一个**具体的新问题**，而且这个新问题要有明确的下一步动作。如果重定义之后还是一片模糊，说明你没找到门。

## 三个版本的质量门（细化）

三个版本生成后，逐道门自查。任何一道没过，回到对话里补问，不要硬写报告。

1. **差异门**：三个版本的核心动作各写一句话。版本二和版本三如果写出来差不多，追问「这两个的区别到底在哪」。
2. **真诚门**：三个都真心愿意考虑，没有凑数备胎。用户说「这个不现实」时，追问「不现实的是哪一部分——钱、能力，还是别人的眼光」，通常只是其中一个。
3. **具体门**：每个版本都能说出五年后一个普通周二怎么过。说不出来的版本是幻想，不是计划。
4. **代价门**：每个版本都有明确的放弃项。没有代价的版本说明还没想透，追问「走这条路，你要放弃什么」。

## 备选主问题（四阶段已覆盖、但还有额度时用于收敛）

优先级从高到低：

1. **「在什么场景下，你会觉得『我不像我自己』？」** —— 反向定位，往往能精准圈出方向失效的环境。
2. **「如果你现在做的这件事，保证不会失败，你会怎么做得不一样？」** —— 绕过对失败的防御，暴露真实偏好。
3. **「最近一次你觉得『活着真值』，是在做什么？」** —— 直接锚定高能量时刻。
4. **「有没有谁的生活，是你看到会有点酸、但说不清为什么的？」** —— 嫉妒的颗粒度越细，信号越强。

## 追问的三个优先级

当同时有多个点想追问时，按这个顺序选：

1. **能改变最终判断的**（比如区分「擅长但消耗」和「真的想要」）
2. **能把抽象变具体的**（要场景、要时间、要原话、要具体画面）
3. **用户自己流露情绪但没展开的**（他说到某处突然多说了两句，或者语气变了——那里有东西）

不要追问：已经说清楚的细节、和主线无关的好奇心、或者你自己想显摆洞察力的问题。
