# 四条主线 · 问题库与信号识别

本文件是 SKILL.md 的支撑材料。主线顺序可灵活调整，但四条必须全部覆盖。

**额度规则**：主问题最多 10 个（下表列出的都是主问题）。苏格拉底式追问**不计入额度**，想追就追。典型分配是每条主线 2 个主问题 + 若干追问，留 2 个余量给意外发现的线索。

---

## 主线一 · 童年自发区（16 岁以前）

16 岁前的自发行为权重最高——那时还没有人给你打分、没有绩效、没有「应该」，行为最接近本能。

### 主问题 1.1（默认开场第一问）

> 在 16 岁以前，有没有什么事情，是没有任何人要求你、也没有人给你任何回报，你却会自己废寝忘食去做的？

**追问钥匙**（用户回答后按需插入，不要一次全问）：
- 「当时大概几岁？」
- 「能说一个具体的场景吗？那天发生了什么？」
- 「做这件事的时候，是什么感觉？」
- 「如果有人叫你停下来去吃饭，你会怎么样？」
- 「持续了多久？是一阵子，还是持续了好几年？」
- 「有没有人知道你在做这件事？他们什么反应？」

### 主问题 1.2

> 从小到大，有没有哪个「缺点」是被反复批评、你也努力改过，但一直没改掉的？

**追问钥匙**：
- 「第一次因为这个被批评，是什么时候、被谁？」
- 「他们当时用的原话是什么？」
- 「你试过怎么改？改的时候什么感觉？」
- 「现在这个特点还在吗？在什么场合它会变成优点？」

### 这条主线的信号识别

| 用户说 | 可能指向的底层天赋 | 需要再验证什么 |
| --- | --- | --- |
| 一个人拆东西、组装、搭东西 | 系统构建、结构直觉 | 拆完是否要重组出新的东西？还是只为弄懂？ |
| 组织小伙伴玩、分配角色、定规则 | 统筹、影响他人、秩序设计 | 是享受「大家在玩」，还是享受「按我设计的在玩」？ |
| 沉浸看书/看百科/查资料忘记时间 | 深度吸收、模式识别 | 看完之后会不会自己输出（讲给别人、写下来）？ |
| 编故事、画画、沉浸在自己的想象世界 | 意义建构、原创表达 | 那个世界是逃避现实，还是你主动在建的？ |
| 反复被批评「太较真 / 钻牛角尖」 | 精密、标准感、求真 | 较真的时候，是难受，还是其实有点爽？ |
| 反复被批评「话太多 / 太爱表现」 | 表达、联结、感染 | 被批评之后，你收敛了吗？还是换个地方继续？ |
| 反复被批评「不合群 / 老走神」 | 独立判断、内在参照系 | 走神的时候脑子里在做什么？ |
| 反复被批评「爱管闲事 / 太操心」 | 责任担当、系统维护 | 这事不管，你是真的难受，还是只是习惯？ |

**改不掉的缺点 = 高价值信号。** 一个能被改掉的缺点只是习惯；一个反复被批评、努力改过却始终改不掉的，说明它是底层配置，只是被环境当成了缺陷。

## 主线二 · 无意识胜任区（成年后）

这里的标志是「这还需要学吗」。人对自己的天赋往往毫无感觉，因为对它来说太容易了，默认以为别人也一样。

### 主问题 2.1

> 成年以后，在工作或生活里，有没有哪些事你会觉得「这还需要学吗」，但周围人普遍觉得挺难的？

**追问钥匙**：
- 「能说最近一次吗？当时是什么情况？」
- 「对方是怎么反应的？」
- 「你第一次意识到『别人好像不这样』，是什么时候？」
- 「你是怎么做到的？能不能把当时的思路说一遍？」（注意：这一步他往往说不清，说不清本身就是证据）

### 主问题 2.2

> 别人最常因为什么事情，专门来找你帮忙或请教？

**追问钥匙**：
- 「最近一次是谁，为什么事？」
- 「他们通常会怎么描述你？」（转述他人的评价，比自评更准）
- 「帮完以后你什么感觉？是乐意，还是觉得麻烦？」
- 「有没有什么事是你觉得『这种小事也要问我』的？」

### 这条主线的信号识别

- **说不清过程 = 强信号**。天赋因为太自动化，往往无法拆解步骤。用户说「我就是觉得应该这样」，这是典型表现。追问「你是怎么做到的」，他答不上来，反而印证了这是无意识胜任区。
- **被请教的频率比难度更重要**。一件事如果只被请教过一次，可能是偶然；反复被不同的人就同一类事请教，那是模式。
- **注意「这不算什么」**。用户会贬低自己的天赋，说「这谁都会」。顺着问「那你身边有几个人会？」，往往能戳破。

## 主线三 · 能量地图

**这条主线是整个流程的分水岭**。它把「擅长」和「天赋」分开，是本技能区别于所有职业测评的关键。

### 主问题 3.1

> 有没有哪些事情，做完以后身体其实挺累的，但精神上特别亢奋，甚至不想睡觉？

**追问钥匙**：
- 「最近一次是什么时候？」
- 「那种亢奋具体是什么样的？脑子里在转什么？」
- 「如果没人催你、也没报酬，你还愿意做吗？」
- 「做这个的时候，会忘记时间吗？」

### 主问题 3.2

> 反过来，有没有哪些事情你做得其实很好、别人评价也不错，但做完明显被抽干，需要缓很久？

**追问钥匙**：
- 「被抽干是什么感觉？是空、是烦、还是身体上有反应？」
- 「要缓多久？」
- 「既然这么累，为什么还在做？」
- 「如果可以不做，你第一反应是解脱，还是舍不得？」（这一问非常关键）

### 这条主线的信号识别

| 表现 | 归类 |
| --- | --- |
| 做得好 + 做完回血 | **天赋区** —— 报告的正面核心 |
| 做得一般 + 做完回血 | **待开发区** —— 天赋还没被训练，潜力最大 |
| 做得好 + 做完抽干 | **高消耗区** —— 是被训练出来的能力，不是天赋。必须单独列出，不许混进天赋清单 |
| 做得一般 + 做完抽干 | **止损区** —— 现实里应尽量减少 |

**「待开发区」是最容易被错过的。** 做得一般但做完精神亢奋的事，说明能力还没长出来，但底层驱动是真实的——这往往是最值得在 30 天实验里投入的方向。

**关于「既然这么累，为什么还在做」的追问**：答案往往会牵出外部期待（父母的期望、行业的惯性、已经投入的沉没成本）。这是阴影面的重要入口。

## 主线四 · 嫉妒与渴望

嫉妒是最诚实的信号——人不会嫉妒自己真正无感的东西。嫉妒指向的是你压抑的、或者认为自己不配拥有的部分。

### 主问题 4.1

> 你曾经强烈嫉妒过谁吗？或者，你羡慕过哪种生活状态？

**追问钥匙**：
- 「那个人的什么，最让你不舒服？」
- 「如果可以和他交换一样东西，你会换什么？」
- 「你第一次有这种感觉是什么时候？」
- 「这种感觉现在还有吗？」
- 「你觉得他配得上他拥有的东西吗？」（这一问常能区分「嫉妒」和「不甘」）

### 主问题 4.2（深挖，必问）

> 你羡慕的那个东西，如果把它拆开——你真正渴望的，是他拥有的那个结果，是他做事时的那个状态，还是他被对待的那种方式？

**追问钥匙**：
- 「如果他失去那个东西，但还保有那个状态，你还羡慕吗？」
- 「你想要的，是『被看见』，还是『做成这件事』？」
- 「这个渴望，你有没有跟别人说过？」

### 这条主线的信号识别

- **嫉妒的颗粒度越细，信号越强。** 「我嫉妒他成功」没用；「我嫉妒他能在会上直接说出那个所有人都不敢说的话」——这是高纯度信号。
- **区分三个层次**：羡慕结果（房子、title、收入）→ 羡慕状态（自由、专注、被需要）→ 羡慕能力（敢说、能扛、看得清）。**第三层才是天赋线索**，前两层只是欲望。
- **嫉妒里带羞耻感的地方，是核心。** 如果用户说「我嫉妒他，我知道这样不好」——那个「不好」背后藏着的，往往是他从小被教导「你不配」的那个部分。

## 备选主问题（前四条主线已覆盖、但还有额度时用于收敛）

优先级从高到低：

1. **「在什么场景下，你会觉得『我不像我自己』？」** —— 反向定位，往往能精准圈出天赋失效的环境。
2. **「如果保证不会失败，也不用担心钱，你会去做什么？」** —— 老问题但有效，注意追问「为什么是这件」，防止得到空想答案。
3. **「如果不考虑现在的履历，你觉得自己本来应该做什么？」** —— 「本来应该」这个词会绕过现实防御。
4. **「最近一次你觉得『活着真值』，是在做什么？」** —— 直接锚定高能量时刻。

## 追问的三个优先级

当同时有多个点想追问时，按这个顺序选：

1. **能改变最终判断的**（比如区分「擅长但消耗」和「天赋」）
2. **能把抽象变具体的**（要场景、要年龄、要原话）
3. **用户自己流露情绪但没展开的**（他说到某处突然多说了两句，或者语气变了——那里有东西）

不要追问：已经说清楚的细节、和主线无关的好奇心、或者你自己想显摆洞察力的问题。
