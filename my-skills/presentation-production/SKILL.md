# 演示文稿制作

本入口只安装在专业工作空间，负责从请求到成品的接续。交付属于办公任务，内部写程序不改变类别。

1. 从用户请求和工作空间已有素材提取目的、受众、事实来源与格式。未指定格式时采用可编辑 PPTX；非关键页数、配色等自行选择并简述，关键事实不可编造。
2. 在当前工作空间 `presentation-work/` 准备大纲、素材和制作文件；最终文件放 `presentation-outputs/`，避免污染知识笔记。维护现有成品时保留原件，按用户要求修改。
3. 直接完成策划、制作和内部检查。用户只要大纲才止于大纲；要成品时不要让用户传递制作说明。需要共同创作时按明确请求进行。
4. 优先使用当前宿主可用的演示、文档或浏览器工具。若使用本地程序，先核对已安装环境，按工具说明执行；不假定特定助手或系统必有某个工具。
5. 工作空间 `.agent-assets/presentations/` 保留第三方资料：humanize-ppt 供叙事方法，ppt-master 供 PPTX 工具与模板，frontend-slides/guizang-ppt-skill/beautiful-html-templates 供 HTML 样式，baoyu-slide-deck 供图像演示方法。只读取当前步骤需要的工具说明或样例，不执行其整套批准、工具更新、偏好保存流程。保留版权、归属和模板使用条件。
6. 完成事实、页数、格式和实际呈现检查。PPTX 应检查文件可打开并渲染查看；HTML 应实际打开检查溢出、翻页与可读性。无法渲染时如实指出未完成的检查，不声称视觉通过。
7. 达到目标后交付可点击成品与简短说明。可选预览、保存长期偏好、自动更新、发布和工具维护不默认阻塞制作；新增费用、关键事实缺口及未授权对外行动遵循全局批准边界。
