# 咖啡店可行性推演：50万预算 + 3万月租铺子

> 方法说明：不引用外部资料，只用基础商业算术和公开常识性的行业结构做第一性推演。所有数字均为假设，标注了每个假设对结论的敏感度。缺什么数据会在文末明确列出。

---

## 一、先把问题翻译成数学题

一家店"成立"只有一个定义：**在投资回收期内，每月经营现金流为正，且累计现金流覆盖初始投入**。

拆成三个子问题：

1. **固定成本每月多少？** —— 决定盈亏平衡点
2. **这家铺子的物理和位置上限能卖多少？** —— 决定收入天花板
3. **盈亏平衡点与天花板的距离多远？** —— 决定这件事成不成立

---

## 二、成本侧推演

### 2.1 初始投入（50万怎么花）

| 项目 | 估算 | 说明 |
|---|---|---|
| 转让费/顶手费 | 10–15万 | 月租3万的商圈铺通常有转让费；这是最容易被低估的一项 |
| 装修（含水电改造） | 15–20万 | 按150–250㎡或60–100㎡高密度装修两种口径都会落在这个区间 |
| 设备（咖啡机、磨豆机、制冰、冷藏、POS等） | 8–12万 | 商用半自动+磨豆机是双头起步约5–8万 |
| 首批原料 + 杂项 | 2–3万 | |
| **备用金（必须留）** | **≥10万** | 见下文，这是生死线 |

注意：如果转让费+装修吃掉30万以上，备用金只剩不到15万——按下面的月亏损模型看，这个缓冲只够撑2–3个月的不及预期期。**50万里真正能"错"的额度非常小。**

### 2.2 每月固定成本

| 项目 | 估算 |
|---|---|
| 租金 | 30,000 |
| 人力（2全职+1兼职，二线城市口径） | 18,000–25,000 |
| 物业+水电（咖啡馆水电耗不小） | 6,000–9,000 |
| 杂费（平台、耗材、维摊销外的现金支出） | 2,000–4,000 |
| 折旧摊销（非现金流，但回收计算需要） | 约15,000（35万分36个月） |

**每月现金固定成本：约 56,000–68,000 元，取中值 ~60,000。**

### 2.3 毛利结构

现制饮品毛利率行业常识区间为 55%–70%（咖啡豆奶冰成本低，但商圈铺损耗、外送折扣会压低）。取 **65%** 做基准。

### 2.4 盈亏平衡点

```
保本营业额 = 固定成本 / 毛利率 = 60,000 / 0.65 ≈ 92,300 元/月
```

按客单价分层换算成杯数/客流：

| 客单价 | 月保本营业额对应订单数 | 日均订单（按30天） |
|---|---|---|
| 25元 | ~3,700 单 | ~123 单/天 |
| 32元 | ~2,900 单 | ~96 单/天 |
| 40元（含轻食甜点拉升） | ~2,300 单 | ~77 单/天 |

**关键结论一：你需要日均约 80–125 单才能保本。**

## 三、收入侧推演：这个数到底可不可能？

### 3.1 从租金反推位置质量

月租3万，按餐饮业常见的"租售比不超过15%–20%"健康线反推：

- 租金占营业额 15% → 稳态月营业额应达 **20万**
- 租金占营业额 20% → 月营业额至少 **15万**

也就是说，**房东用3万租金给你定了一个隐含门槛：这间铺子在他/她的定价逻辑里，应该能做出月流水15–20万以上的生意**（可能是餐饮、零售，不一定是咖啡）。做不到，说明你付的钱和你的业态不匹配——这是选址层面第一个要核验的点。

### 3.2 咖啡单店的现实产出

常识区间（无外部数据，仅凭业态结构的合理推断）：

- 一线城市成熟商圈独立咖啡店：日均 100–200 单算不错，头部网红店 300+
- 普通商场店/街边店：日均 40–80 单是常态
- 保本线以下的店大量存在，这正是"九死一生"的统计学来源

对照保本线：

| 场景 | 日均单量 | 月毛利（65%） | 月现金盈亏 |
|---|---|---|---|
| 悲观 | 50 单 × 28元 = 42,000 | 27,300 | **-32,700** |
| 中性 | 90 单 × 30元 = 81,000 | 52,650 | **-7,350** |
| 乐观 | 140 单 × 33元 = 138,600 | 90,090 | **+30,090** |
| 很乐观 | 200 单 × 33元 = 198,000 | 128,700 | +68,700 |

**关键结论二：中性情景（日均90单）在这个成本结构下依然是微亏的。** 你的成本结构要求你必须做到"乐观档"以上才成立。这不是鸡汤或劝退的问题，是这个租金水平把及格线抬到了行业前 20%–30% 的经营水准。

### 3.3 结构性矛盾

- 3万月租 → 要求高客流 → 只能选商圈/商场位置 → 商圈位置意味着周边有瑞幸/幸运咖/Manner等连锁，价格锚被压到9.9–20元 → 你的客单价和复购被系统性压制。
- 反过来，能卖出高客单价（35元+）的精品/空间型咖啡馆，往往开在低租金社区/街巷，靠目的性消费——但那不是3万月租的铺子。

**这就是这道题的核心死结：3万月租的铺子天然把你推向与连锁正面竞争的位置，而独立店在这场竞争里没有成本优势。**

## 四、回收期测算

即使做到乐观档（月现金净流入3万），相对35万左右的真实投入（扣除备用金），回收期约 **12个月以上**，且前提是从第一个月起就维持140单/天——新店爬坡期（3–6个月）几乎不可能。

更现实的路径：中性偏乐观爬坡6个月，之后稳定在120单：
- 前6个月累计亏损约 10–15万
- 之后每月净流入 1.5–2万
- 回收期拉长到 **30–40个月**

而餐饮商铺租约通常"1+X"，第二年大概率涨租或面临续约博弈。**回收期超过一个租约周期，风险敞口显著放大。**

## 五、敏感性分析：哪些变量翻盘？

按影响力排序：

1. **租金（最大杠杆）**：租金从3万降到2万，保本线直接从~9.2万降到~7.4万营业额，日均保本单量降到 75–95 单——从中性情景即可存活。**同一个项目，租金差1万，结论可以从"不成立"变成"勉强成立"。** 这是你唯一能在签约前改变的最大变量。
2. **客单价结构**：如果轻食/甜品/烘焙能把客单价从28拉到40，且毛利率不低于60%，保本单量降到77单/天。但轻食会增加人力和损耗，不是免费午餐。
3. **转让费**：转让费每多5万，等于白干2–3个月的乐观利润，还压缩备用金。
4. **人力模式**：夫妻店/主理人自己站吧台，省1.5–2万/月人力，保本线降到 ~7万营业额。**很多活下来的独立咖啡馆本质是"给自己发工资"而不是"赚投资回报"。**

## 六、判定

### 在当前给定条件下（50万预算 + 3万月租 + 独立咖啡店主业态）：**不成立，或者严格说——成立条件极其苛刻。**

成立的必要条件清单（全部满足才行）：

1. 实测该位置日均自然人流中，愿意为25元+咖啡停留的转化能支撑 100+ 单/天（需实地蹲点验证）
2. 周边500米内无瑞幸/库迪/Manner贴身价格战，或你的产品有明确的差异化护城河（空间、烘焙、B端生意）
3. 租约能谈到免租期≥2个月、年涨幅≤5%、租期≥3年
4. 转让费+装修控制在25万以内，保留≥15万备用金
5. 你本人（或合伙人）全职站店，把人力成本打下来

### 更可能成立的替代形态（同样的钱、同样的商圈偏好）：

- **砍面积降租金**：找月租1.5万以内的位置做外卖+自提为主的小店（20–40㎡），保本线降到4–5万营业额，50万预算绰绰有余
- **换业态组合**：咖啡+烘焙/brunch，用高客单时段养低客单时段
- **先验证后重仓**：用快闪/档口/市集摊位花2–3万测同商圈的真实转化率，再决定是否签3万的铺

---

## 七、缺什么数据（如果要认真决策，必须补齐）

本分析全部基于假设区间，以下任一数据的缺失都足以推翻结论：

1. **铺位实测数据**：该点位日均人流量、客群构成（上班族/居民/游客比例）、竞品数量与排队情况
2. **转让费与租约条款**：转让费具体数额、免租期、递增率、租期、能否办出餐饮执照（很多商圈铺是写字楼性质，办不出食品证，这一条就能一票否决）
3. **当地人力成本**：一二三线城市全职咖啡师月薪差异极大（4k–8k+社保）
4. **目标城市咖啡消费水位**：当地人均咖啡杯数、外卖咖啡占比、9.9元价格战的渗透程度
5. **铺面工程条件**：是否具备餐饮排烟/上下水/燃气条件，不具备则装修预算上浮5–15万

---

## 结论一句话

**朋友说的"九死一生"不是情绪，是统计：在3万月租的成本结构下，你需要做到行业中上游的经营水平才能保本，而50万里能承受试错的余量只有几个月。这件事不是不能做，而是在当前给定的两个数字（50万、3万）下，数学上不站在你这边。先谈租金、先测客流、先想清楚差异化——这三个动作做完之前，不要签任何合同。**
