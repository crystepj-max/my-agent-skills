# 3 万块外包美术：先别掏，但别挂电话

## 先说结论

**不要现在一次性掏 3 万。但不要拒绝这个画师——用 2~3k 和两周时间，把"3 万一锤子买卖"拆成"一次可随时叫停的小额试跑"。**

你纠结的不是"美术值不值 3 万"，而是两个完全不同的问题被揉在一起了：

1. **这个画师值不值 3 万**（能力、沟通、交付可靠性——你目前零信息）
2. **美术本身对你的项目值不值 3 万**（边际收益——你目前零数据）

这两个问题任何一个没验证就付全款，都是在用 3 万买一个"感觉"。而这两个问题，加起来大概 3 千块 + 两周就能拿到七八成答案。

---

## 我替你补的假设（说得不对你自己修）

- 你是**个人开发者，没有稳定副业收入**，3 万是你可动用的绝大部分现金，花完 runway 接近归零。
- 这是**免费发布的 MOD**，短期没有直接变现路径（创意工坊/社区分发）。
- 对方是**个人画师或小工作室**，不是有流程的公司，你对他的过往交付没有可核实的口碑。
- "一套角色立绘和动画"**范围未定义**——几个角色？每个角色几个动画？什么风格？几轮修改？源文件给不给？
- 你现在的"粗糙画面"是**占位素材级别**，主玩法已经能完整跑一局。

这几条假设里，任何一条不成立，后面的权重就要调。特别是最后一条：如果你的美术已经不是占位级而是"能用但不好看"，那结论会明显不同。

---

## 为什么现在掏 3 万是个坏赌注

**1. 你在赌的是"美术是瓶颈"，但你没有证据。**

4 个月跑通主玩法、画面粗糙——这个组合最常见的真实瓶颈不是画面，是**没人知道这个项目存在**。花 3 万把画面从 40 分提到 80 分，如果只有 50 个人看到，收益是零。反过来，花 300 块和两周做宣发，如果能把 50 个人变成 500 个人，收益可能更大。先把"是没人看"还是"看了嫌丑"分清。

**2. 沉没成本在推你。**

做了 4 个月，人天然会想给它配"配得上"的美术。但 4 个月的投入不产生"应该再投 3 万"的义务。判断要不要投钱只看一件事：**从今天往后看，这笔钱换回来的东西值不值**。过去的 4 个月跟这个决定无关。

**3. 3 万一次性付出去，是不可逆的。**

美术外包最常见的翻车点，全都在"一次性付全款"这个动作上被放大：风格跟你想象的不一致、动画和立绘是两种完全不同的能力（画得好的画师不一定会做动画）、改稿无底洞、交付延期、源文件不给、版权归画师。这些风险里没有一个需要你先付 3 万才能发现。

**4. 时机上有个技术性风险：STS2 还在抢先体验期。**

游戏本体在持续更新，MOD API、UI 框架、美术规格都可能变。游戏内容没定型之前做的定制美术，有实打实的返工风险。这不是说不能做，是说**现在做，你买的是一份可能要重做的资产**。

---

## 但美术不是不重要——别把它想反了

我把上面说得挺狠，但方向别搞错：**对 MOD 来说，第一印象就是下载量**。玩家在创意工坊列表里滑过你的封面图只用 0.5 秒，画面粗糙在这一关就会被刷掉，玩法再好也没机会被看见。所以美术肯定要做，问题只是**什么时候做、做多大、给谁做**。

---

## 五个低成本验证实验

按性价比排序，建议至少跑前两个。

### 实验 1：单图试跑（最重要，必做）

**做什么**：跟画师谈，先做**一张**角色立绘 + **一个**动画（比如攻击动作）。报价应该在 2~3k。不要谈整套。

**成本**：2~3k，1~2 周。

**看什么**：
- 出图质量是不是你要的——不是"好不好看"，是**放进你的游戏里**好不好看（让他出图时给个在游戏截图上的合成预览）
- 沟通成本：你描述需求他能不能一次听懂，改稿 1~2 轮能不能到位
- 交付习惯：给不给分层源文件？动画给不给序列帧或工程文件？按时吗？

**怎么判读**：
- 满意 + 沟通顺 + 给源文件 → 这个画师可以合作，进入实验 2
- 不满意但画师态度好、愿意改 → 说明是你的需求描述问题，不是画师问题，值得再试一次
- 不满意 + 拖稿/不给源文件/拒绝小额试跑 → **恭喜，2~3k 买到了一个"不要花 3 万"的确定答案**

**顺带说**：一个靠谱的画师会接受小额试跑。拒绝试跑、坚持要全额预付的，这件事本身就是最强的风险信号。

### 实验 2：剥离变量，测美术的边际收益

**做什么**：你现在就有能跑的版本。做两个版本的素材发出去对比：
- A 版：当前粗糙版
- B 版：只把主角立绘换成实验 1 那张高质量图（**只换一张**，其它什么都不动）

发到 B 站/小红书/创意工坊/相关 Discord，看数据。

**成本**：几乎为零（图已经有了）。1~2 周观察期。

**看什么**（按重要性排序，别看点赞）：
1. **预约/订阅/加群数**——这是唯一算数的
2. 播放完成率 / 试玩留存
3. 评论里主动提到"美术""画风"的比例

**怎么判读**：如果 B 版在订阅转化上有明显提升（哪怕只是评论里"美术好看"的比例从 5% 涨到 25%），说明美术确实是你的瓶颈，3 万有依据。如果两版数据差不多、评论区全在讨论玩法——那你的瓶颈在别处，这 3 万省下来。

### 实验 3：假门测试（如果实验 1 还没谈拢，先用这个垫着）

**做什么**：用 AI 生成或者自己简单上色，做几张"假装这是成品"的立绘，发帖问社区："如果这个 MOD 的美术长这样，你们会玩吗？"

**成本**：0~几百块，2~3 天。

**看什么**：注意别看点赞，**看"愿意预约/加群"的人数**，以及评论区是不是在问"什么时候出"。

**怎么判读**：这个实验的证据强度比实验 2 弱（人们说会玩 ≠ 真的会玩），但它便宜到可以忽略成本，适合先探路。

### 实验 4：验证画师，而不是验证美术

在你付任何钱之前，这几件事先做（都免费）：
- 要**动画**作品集，不是立绘作品集。这是两种能力，很多人只会前者
- 要一个跟你项目风格接近的过往案例（像素/厚涂/二次元，风格迁移是有风险的）
- 问清楚：修改几轮？超了怎么算钱？源文件交付格式？版权归谁？延期怎么办？
- 如果能找到他以前的委托人，私下问一句"交付顺利吗"

### 实验 5：验证你自己——算 runway

**做什么**：拿张纸算：3 万付完之后，你账上还剩多少？够活几个月？

**怎么判读**：
- 剩下 ≥ 3 个月生活费 → 这是一笔可以承受的投资
- 剩下 < 1 个月 → **这不是投资，这是赌博**。不管美术多值，都不要在这种情况下把现金流清零。活下去的自由度比一张立绘值钱。

## 如果你决定掏钱：把风险砍掉一半的四个动作

1. **分阶段付款，绝不全额预付。** 建议 3-3-4：30% 启动 / 30% 中期看线稿和上色 / 40% 全部交付验收后。任何坚持全额预付的，一票否决。

2. **合同里必须写死版权。** 这一点很多人吃亏：**委托创作的著作权，合同没写明归你的，法律上默认归画师**（《著作权法》第 19 条）。你付了 3 万，结果图不是你的——这种事真实发生过。合同里必须白纸黑字：著作权归委托方所有。

3. **范围写死，防范围蠕变。** "一套"是个会吃掉你预算的词。写清：几个角色、每个角色几个动画、分辨率、风格参考图（直接附参考图，别用文字描述风格）、几轮修改、超一轮多少钱。

4. **按角色拆批，保留叫停权。** 别一次性签"一整套"。谈成"第一个角色 X 元，效果 OK 再按同价续下一个"。这样你随时能停在最合适的位置。

---

## 给你一个明确的判据，别再靠感觉

不要问自己"值不值"，问"满足什么条件我就掏钱"。建议把线画在这里：

**同时满足这四条，才掏 3 万：**

- [ ] 实验 1 的单图试跑让你满意，且改稿 2 轮内到位
- [ ] 实验 2 显示有美术的版本在订阅/留存上有可观测的提升
- [ ] 付完钱，账上还剩 ≥ 3 个月生活费
- [ ] 对方接受分阶段付款 + 合同写明版权归你 + 按角色分批

**任何一条不满足 → 先解决那一条，不要掏钱。**

---

## 最后一句

3 万块还有个你可能没算进来的用法：**它等于你继续做这个项目两个月的时间**。

这笔钱可以买一套立绘，也可以买你两个月不用为钱分心。哪个回报更高，取决于你的项目现在真正卡在哪——而这件事，你现在还不知道。所以先花 3 千和两周把它搞清楚，再决定剩下 2 万 7 怎么花。

你只有一次机会花这 3 万，但你可以花十次机会去验证它该不该花。
